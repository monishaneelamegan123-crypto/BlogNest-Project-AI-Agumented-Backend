# AI Blog Nest

AI Blog Nest is a secure blogging and content-management platform built with:
- Node.js
- Express.js
- MongoDB / MongoDB Compass
- Google Gemini API
- JWT authentication
- Role-based access: Admin, Editor, Author, Reader
- HTML, CSS and JavaScript frontend
- AI blog ideas, content improvement and AI chatbot
- Social features: likes, comments, follows and saved posts

## Run

1. Install Node.js.
2. Start MongoDB locally.
3. Open `backend` in terminal:
   `npm install`
4. Copy `.env.example` to `.env` and add your Gemini API key.
5. Run:
   `npm run seed`
   `npm run dev`
6. Open the frontend with VS Code Live Server:
   `frontend/index.html`
